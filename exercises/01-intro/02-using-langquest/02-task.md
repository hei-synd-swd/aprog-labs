# Working with LangQuest

Show that you know your way around LangQuest. Open the answer file with `e` and, **below** the `<!-- Write your answer below -->` line in `main.md`, answer the questions in your own words.

## Your Task

Address all of the following:

1. Which **key** opens the current exercise file in your editor?
2. What happens when you press `h` to reveal a hint - is it **recorded**? What about viewing the solution?
3. How do you move **between the pages** of an exercise (Theory, Task, Debug, Output, Solution)?
4. **How and when** are an exercise's tests run?

## Expected Result

Your answer mentions the editor key, that hint (and solution) reveals are recorded, the arrow keys for page navigation, and that tests run automatically when you save. LangQuest checks your answer for these concepts - you pass once enough of them are covered (75%).
